# Shopping List

A WPF desktop application for managing shopping lists and grocery item catalogs.

## Features

- Add items to a shopping list and track purchases with checkboxes
- Clear purchased items in one click
- Maintain a personal catalog of grocery items with images
- Search the internet for item images via reverse image search
- Track purchase frequency and last-purchased date for catalog items
- Quickly add catalog items to your shopping list

## Tech Stack

- .NET 10.0 (Windows)
- WPF for the UI
- C# with Nullable reference types enabled

## Getting Started

1. Open `shoppinglist.slnx` in Visual Studio or VS Code with the .NET workload installed
2. Build and run the project

```bash
dotnet run
```
